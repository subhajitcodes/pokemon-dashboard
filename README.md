# Pokémon Dashboard

A Pokémon dashboard built with HTML and CSS, inspired by a Pokémon-themed UI design.

## 🌐 Live Demo

(https://subhajitcodes.github.io/pokemon-dashboard/)

## ✨ Features

- Pokémon cards with images, names, IDs, and types
- Type-based colors and styling
- Pokémon stats and details
- Responsive layout
- Custom SVG icons and visual assets
- Clean, Pokémon-inspired interface

## 🛠️ Built With

- HTML5
- CSS3
- SVG assets

## 📁 Project Structure

```text
ASS1/
├── images/
├── index.html
├── style.css
└── README.md
```

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/subhajitcodes/pokemon-dashboard.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

This is a front-end project created for practice and learning. It uses static HTML and CSS.
